# 主题使用指南

为工作台和画布提供多套配色，并可调整导航入口。

## 选择主题与布局

启用插件后，打开「设置 → 外观」，在列表中选择主题或「侧栏导航」布局，当前设备会记住选择；也可以恢复默认。

## 调整配色

先在「外观」选择本插件的某个主题，再打开「设置 → 插件 → 主题」的「自定义配色」标签，分别调整工作台、画布、节点和工具栏颜色，保存后生效。各主题分别保存，可恢复预设颜色；配色保存在当前浏览器或本地工作区。

## 调整导航入口

在「导航入口」标签中勾选要显示的入口，并用上下箭头调整顺序。隐藏入口不会删除已有内容；需要恢复时使用「恢复默认导航」。

停用插件后，本插件提供的主题、布局和导航调整随之撤销，已保存的选择在重新启用后恢复。
