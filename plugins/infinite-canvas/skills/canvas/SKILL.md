# Infinite Canvas

你正在帮助用户操作 Infinite Canvas 网页画布。需要理解或改动画布时，优先使用已配置的 `infinite-canvas` MCP 工具；不要让用户手动复制 JSON、URL 或 token。

## 工作流

- 如果用户还没有打开或连接网页画布，使用 `open-canvas` 技能打开 Infinite Canvas，不要要求用户手动复制 URL 或 token。
- 操作前先用 `canvas_get_state` 读取当前画布；如果用户明确提到选中内容、当前节点或“这个”，先用 `canvas_get_selection`。
- 创建单个文本内容优先用 `canvas_create_text_node`。
- 创建生成内容优先用 `canvas_generate_text`、`canvas_generate_image`、`canvas_generate_video`、`canvas_generate_audio`。
- 需要把提示词、配置和生成节点串成流程时，使用 `canvas_create_generation_flow` 或项目已有的流程工具。
- 需要批量增删改、移动、连接节点或设置视口时，使用 `canvas_apply_ops`。
- 生成失败后先定位已有的提示词、配置和结果节点；参数可修复时原地更新已有节点并用 `canvas_run_generation` 重试，不要再次调用会创建完整流程的 `canvas_generate_*`。
- 不要模拟鼠标点击，不要要求用户手动复制 JSON。
- 写入画布的操作会由网页侧边栏做二次确认，按当前工具结果继续推进即可。

## 生成失败与原地重试

- 生成工具返回失败时，先用 `canvas_get_state`（必要时配合 `generation_get_status`）读取失败节点的真实 `id`、metadata、位置和连线，判断失败原因后再处理；不要把一次失败直接当成新建流程的理由。
- 对宽高不是 16 倍整数、尺寸超范围、比例/数量/质量/模型参数不合法等可由参数修复的错误，保留原提示词节点、配置节点和结果节点的 `id`、位置及已有连线，只更新对应配置节点的 metadata（单节点用 `canvas_update_node`，需要改提示词时用 `canvas_update_node_text`），然后对原配置节点调用 `canvas_run_generation`。多项参数一起修正时使用 `canvas_apply_ops` 的 `update_node`，最后只触发这条原有链路。
- 重试已有链路时不得调用 `canvas_generate_text`、`canvas_generate_image`、`canvas_generate_video` 或 `canvas_generate_audio`，这些工具会创建新的生成流程；除非用户明确要求创建新的独立方案，否则不要新增提示词、配置、结果节点或重复连线。
- 鉴权、额度、网络、服务端、内容审核或无法从当前画布修复的错误，不要复制或新建链路；保留失败现场并向用户说明原因和下一步。只有原链路已被删除/无法定位，或用户明确要求新的变体、独立流程时，才允许重新创建流程。
- 原地修复后再次读取 `canvas_get_state`，确认原节点 `id`、连线和布局未被替换；若重试产生新的结果节点，仅在工具确实创建了新结果时按“自动排版”规则整理，不能为了重试预先创建占位节点。

## 自动排版

- 任何画布写操作（增删改、移动、缩放、连线或生成）都包含排版责任：写入前后分别用 `canvas_get_state` 读取并验证真实的 `position`、`width`、`height`、`connections`。
- 按“参考素材 → 提示词 → 配置 → 生成结果”从左到右分区；同一流程同一行，不同流程分行，行列间距至少 80px。位置计算必须使用实际节点尺寸，不能重叠或覆盖。
- 复杂调整使用 `canvas_apply_ops` 批量更新相关节点。只有工具确实创建了新节点时，才把重复、错位结果节点纳入整理，不能只移动原节点；异步生成时等结果节点实际出现或任务进入终态后再做最终整理；不要为了排版删除或臆造连线。
- 图片节点优先统一为 260×260 的节点外框；统一外框不等于拉伸内容，图片必须在外框内保持原始比例。若工具只支持直接改变内容比例，则保留原比例，不得强制变形。文本和配置节点默认按 340×240 规划，用户明确指定的位置和尺寸优先，不要擅自移动无关节点。
- 排版后再次 `canvas_get_state`，确认无重叠、连线完整且主要流程在当前视口可见；不通过就继续修正。

## 风格

- 页面文案和画布节点内容默认使用中文。
- 生成节点、配置节点和提示词节点要保持结构清晰，方便用户继续编辑。
- 批量创建节点时注意给节点留出间距，不要堆叠在同一个位置。
- 图片、视频、音频等媒体节点默认保留原始比例；只有用户明确要求自由变形时才改变比例。
- 生成流程尽量少而清楚，优先让用户一眼能看懂节点关系。
