# 调用统计

通过宿主模型调用事件记录调用次数、成功率、耗时、渠道、分组、模型、已返回的 Token 用量，并可查看每次调用的请求和返回摘要。启用后在「设置 → 插件 → 调用统计」查看统计，开启「在侧栏显示调用统计」后侧栏会出现入口；默认统计时间和记录开关在同一处的设置标签中保存，使用说明见 [GUIDE](./GUIDE.md)。

## 本地开发

在仓库根目录运行：

```bash
pnpm install
pnpm --dir plugins/api-stats dev
```

工作台未启动时，在另一终端运行 `pnpm dev`；已有工作台直接使用。刷新开发页面，在「设置 → 插件」启用「调用统计」，从插件设置的「调用统计」标签打开统计页面。修改代码后等待监听完成，再点插件的「重新加载」。已安装的同 ID npm 包优先于开发产物，源码调试前需卸载该安装版本。

通过软件源安装时先运行 `pnpm --dir plugins/api-stats build`，再从该插件目录将包发布到自己的软件源。包名为 `canvas-plugin-api-stats`，当前未发布到公共 npm。详见 [插件开发文档](../../apps/docs/content/docs/development/plugin-development.mdx)。

## 统计口径

- 普通图片、文本、音频按应用发起的一次模型操作记录；批量返回多张图仍是一次操作。耗时包含这次操作等待结果的时间，不是网络延迟测量。
- 视频提交与状态查询分别显示；提交成功只表示取得任务或结果，不代表异步视频已经生成完成。返回失败任务状态的查询标记为失败。
- 内置聊天按 AI SDK 每轮模型请求记录，工具执行不额外计为模型请求；对话摘要单独分类。只汇总模型返回的 Token，不估算缺失用量或费用。
- 这是应用模型调用统计，不是通用网络抓包。脚本内部的多次请求、重试，以及本地服务自行进行的后台轮询没有逐条计数；不统计模型列表读取、资源下载、存储、软件源请求或外部 Agent 自身的模型调用。
- 请求与返回摘要来自宿主统一调用事件，包含提示词、文本消息、工具名、图片/视频/音频数量、参数和返回文本；不包含图片编码、请求头、服务地址或密钥。
- 成功率为成功数除以成功与失败总数；取消、进行中和未确认结果不计入分母。平均耗时只计算成功与失败的调用。
- 只记录插件启用后开始的调用，不补采历史。刷新、重新加载或停用期间未收到结束事件的记录显示「结果未确认」，不猜测结果，也不会自动重试模型。

## 保存与隐私

记录通过插件私有存储保存：Web 使用当前浏览器，本地工作台使用当前工作区。停用或卸载保留已有记录，停用后不再记录新调用。支持按今天、近 7 天、近 30 天、全部时间或自选日期筛选，可叠加渠道、模型、类型和状态。按开始时间归入本地日期，点击按日汇总中的日期可查看当日明细。模型汇总与总览都显示 P95 耗时，即成功和失败的记录中至少 95% 可在这段时间内结束。

「导出筛选记录」下载匹配条件的全部明细为 JSON，包含所有分页，沿用上面的统计口径。

记录不包含密钥、服务地址或请求头；开启「记录请求与返回内容」后，会保存提示词、消息文本、工具名和返回文本摘要，单条提示词/返回最多 8000 字，消息最多保留最近 12 条，图片只记录数量。关闭后新调用不再保存内容，已有记录保留。没有后台上传或自动清理。记录列表分页显示，分页不会丢弃记录；「清空记录」经确认删除全部统计，清空前尚未结束的调用不会重新补回。

## 验收

1. 启用后分别发起图片、文本、音频、视频调用，检查类型和状态；视频提交与查询应分别可见。
2. 使用测试渠道验证成功、失败、取消；流式失败不得显示成功，未知 Token 不得显示成已知用量。
3. 内置聊天触发多轮工具调用时，每轮模型请求独立计数；对话摘要另记一次。
4. 筛选渠道、模型与失败状态，核对汇总；刷新应恢复记录，停用期间的调用不新增记录。
5. 在调用记录中点击「查看」打开详情，核对请求提示词/消息和返回文本；关闭「记录请求与返回内容」后，新记录不再包含这些内容。
6. 清空前先取消确认，记录不变；确认后清空。保存失败时保留当前内存记录并提示重试保存，不会重新调用模型。
