# 调用统计使用指南

查看模型调用次数、成功率、耗时和已返回的 Token 用量，并展开单次调用的请求参数、实际请求与返回，方便定位生成失败或参数问题。

## 开始使用

1. 在插件列表中启用「调用统计」。
2. 在「设置 → 插件 → 调用统计」的「调用统计」标签页查看；如需侧栏入口，在「统计设置」中开启「在侧栏显示调用统计」（默认关闭）。
3. 使用模型生成内容或进行聊天，新的调用会自动出现在统计中。

启用前的调用不会补记。停用插件后停止记录，已有记录会保留。

## 设置

在「设置 → 插件 → 调用统计」的设置标签中修改，点击「保存设置」。

- **在侧栏显示调用统计**：默认关闭，开启后侧栏出现「调用统计」入口。
- **默认统计时间**：选择今天、近 7 天、近 30 天或全部时间，下次打开统计页面时使用，默认近 30 天。
- **记录新调用**：关闭后暂停记录，保留已有记录；正在进行的调用仍会记录最终结果。重新开启后继续记录新调用。
- **记录请求与返回内容**：默认开启。打开后会保存提示词、消息文本、工具名和返回文本摘要，以及图片、音频和视频调用实际发给模型服务的请求，便于排查；关闭后新调用只保留模型、类型、耗时和 Token。

设置属于当前插件，在当前浏览器或本地工作区中保存，刷新、重新加载或停用后仍会保留。

## 筛选与查看

可按时间、调用类型、渠道、模型和结果筛选。切换到「按日统计」查看每日变化，点击日期查看当天明细；「模型汇总」可比较不同模型的调用次数与耗时。

在「调用记录」中点击「查看」，可以查看该次调用的请求参数（提示词、消息、工具名、素材数量、参数）、实际请求和返回摘要（文本、任务状态、错误码）。实际请求是调用方式最终发给模型服务的地址、请求头、请求体以及服务返回的状态和内容，只记录图片、音频和视频调用；文本与聊天不记录。失败的调用会显示错误提示和错误码：模型服务返回了错误说明时显示该说明，否则显示宿主固定提示，不展示地址或密钥。

「导出筛选记录」下载全部匹配记录，不受当前分页影响。「清空记录」需要确认，只删除调用记录，保留插件设置。

## 如何理解数字

- **成功率**：成功次数除以成功与失败的总次数，不包括取消、进行中和结果未确认的调用。
- **平均耗时**：仅统计成功和失败的调用。P95 表示其中至少 95% 的调用耗时不超过这个数值。
- **Token 用量**：仅汇总模型实际返回的用量；没有返回用量时显示「—」，不估算费用。
- **视频调用**：一次视频生成只记一行。提交后显示「进行中」，查询到最终结果后改为成功或失败，耗时为从提交到出结果的总时长；实际请求包含提交请求和最后一次查询。中间「仍在生成」的查询不单独记录。
- **聊天调用**：一次对话可能调用模型多次，每次分别计数，对话摘要单独列出。

统计不包含外部 Agent 自身的调用，也不会逐条记录生成过程内部的重复请求。刷新或停用时尚未收到结果的调用显示「结果未确认」，不会自动重试生成。

## 数据保存

网页版保存在当前浏览器，本地工作台保存在当前工作区。开启「记录请求与返回内容」时会保存提示词、消息文本和返回文本摘要，单条最多 8000 字、最近 12 条消息；图片、音频和视频调用还会保存实际请求，包含服务地址和请求头，其中密钥打码，图片等文件只记录类型和大小。关闭该开关后新记录不再包含内容，已有记录保留。

记录不会自动上传或清理。
