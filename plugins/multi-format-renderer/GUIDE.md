# 多格式渲染器使用指南

在同一画布中编辑网页片段、排版文字和矢量图形。

## 添加内容

启用插件后，从画布创建菜单添加「内容渲染」节点，选中后点工具条的「编辑」，在顶部选择 HTML、Markdown 或 SVG 格式并输入内容，点「预览」查看结果。

- **HTML**：展示网页片段，可使用节点工具栏切换编辑、预览与交互状态。
- **Markdown**：编写标题、列表、代码和链接，查看排版结果。
- **SVG**：编写或粘贴矢量图形内容，查看图形预览。

## 用 AI 生成

单击节点会在下方打开对话框，输入要求后回车或点发送，使用默认文本模型生成当前格式的内容并直接显示。节点已有内容时，会在现有内容基础上修改；连接到节点的上游文本会作为参考。生成前请先在渠道设置中选好文本模型。

## 使用上游文本

将文本节点连接到格式为 HTML 的节点，在 HTML 中使用 {{input}} 引用上游文本，方便将生成文字放入展示模板。

## 操作节点

编辑内容时在编辑器中输入，移动或调整节点时使用节点外部区域与工具栏。需要操作 HTML 预览中的控件时先开启交互。

停用插件后不会删除已有画布内容，重新启用后继续编辑和预览。
