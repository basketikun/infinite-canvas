# WebDAV 同步

在「设置 → 插件」打开 WebDAV 同步的配置，填写服务地址、远程目录、用户名和应用密码。可在启用前保存设置和测试连接；启用后点「立即同步」。WebDAV 默认使用服务根地址下的 `infinite-canvas` 目录。

同步包括画布、画布聊天、独立作品、我的资产，以及图片、视频和音频创作记录。同步完成后可看到每项名称和条数。

同一条目按业务保存时间合并。画布及插件记录的删除也会同步。独立作品保留作品编号、所属插件及其附件，接收端可先同步，启用对应插件后再打开。要接收正在编辑的作品的新版本，请先保存并关闭编辑器。若旧作品提示缺少保存时间，请打开作品做一次编辑并保存，再重新同步。画布、独立作品和插件记录引用的原文件随记录传输。模型密钥、连接密码、插件私有配置和正在执行的模型任务留在本机。Web 模式沿用浏览器的网络设置，本地工作台通过工作区连接。

画布先完成同步，再同步属于它的对话。消息中的参考图和继续聊天所需的图片一起保存，已删除的会话也会同步。正在回复时请等回复结束；收到正在起草的对话的新版本时，请先处理草稿再试。当前选中的对话留在本机。

同步时保持设置打开。关闭设置或停用插件会取消此次操作，已完成的传输会保留。连接设置按插件和所选传输方式分别保存，重新启用后可继续使用。

遇到“原文件缺失或损坏”的提示，请从备份补齐原件，或在作品中重新选择完整文件，保存后重试。若远程目录使用旧版同步格式，请保留原目录，填写一个新的空目录，由保存有完整作品的设备先同步。遇到冲突时，先等两端编辑保存后重试；如果两端的同一文件已经不同，请保留两份原件，在其中一端重新导入该文件并让作品引用新文件，再次同步。

在同步过程中停用、替换或重新启用插件后，请重新同步。

两台设备同时修改同一份远端清单时，支持版本核对的 WebDAV 服务只接收仍与原版本相符的写入。遇到“远端已变更”，请保存当前编辑后重新同步。各项内容分别保存，中途失败时保留已完成的部分，“上次同步”只在整次成功后更新。

连接测试检查地址、账号和目录。失败提示末尾会附上服务返回的原因，例如 `HTTP 507`（空间不足）或网络错误原文。服务地址发生跳转时同步会停止，请填写跳转后的完整地址。若同步时提示无法核对远端版本，请向服务管理员确认支持强 ETag 与条件写入。浏览器跨域直连还需要允许 `If-Match`、`If-None-Match` 请求头，并向浏览器开放 `ETag` 响应头。服务忽略条件写入时，多台设备仍可能互相覆盖，请使用支持该功能的服务。
