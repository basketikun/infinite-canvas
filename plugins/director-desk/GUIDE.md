# 3D 导演台

在「设置 → 插件」启用 3D 导演台。从画布底栏的「扩展节点与工具」选择「3D 导演台」，然后点击新节点里的「打开导演台」。

1. 左侧「场景对象」选择角色、道具或机位，在右侧调整属性。中央视口可切换导演视角和机位视角。窄屏下用「场景」和「属性」打开侧栏。
2. 选择机位或角色，在右侧「轨迹」点「绘制轨迹」。从视口中的起点按住拖画，松开保存。俯视适合画地面走位，正视、侧视可画升降。预览或录制时，角色会沿路线转身、交替迈步，到终点收脚停稳。「移动用时」默认取自这次拖画；调长用时走得慢，调短走得快。重画时按 Esc 取消并保留原路线。
3. 点击视口底部的「拍照」，或从选定机位拍照。图片会添加到画布并与导演台节点连线。「更多工具」可拍摄四方位或十二方位截图。
4. 点击「录制」从零秒同时播放已设置的轨迹，再点击「停止录制」。没有轨迹时也可以手动移动视角或调整场景。当前取景的无声录像会作为视频节点添加到画布。录制中关闭导演台也会结束录制并保存视频。
5. 将图片连入导演台节点后，在场景属性的「全景背景」下点击「使用连接图片」即可设置背景。
6. 在右上角关闭（或按 Esc）会保存场景并回到原画布，再次打开同一节点可以继续编辑。每个导演台节点分别保存自己的场景。

在导演台顶部的「镜头布局」选择「环绕目标」，填写目标对象、距离、相对目标高度和镜头数量，生成后点击「添加镜头」。距离需大于零，镜头数量为正整数，高度可以为负值。原有镜头会保留，整批新增镜头支持一次撤销。关闭布局面板或退出场景会取消尚未应用的结果。

## 编辑体素道具

放置一个几何道具或导入模型，选中后，在属性里选择分辨率和「表面壳」或「实心」，点击「原位体素化」。网格沿用道具的位置与朝向。点「查看源模型」可以对照轮廓。使用视口工具给表面刷色、沿所点面添加一格或擦除一格，误操作可以撤销。较高分辨率和实心模式会增加浏览器内存占用和场景存档大小。

导演台打开时，内置聊天和外部 Agent 可以读取镜头目标、添加环绕镜头，也可以指定对象和格子坐标进行体素编辑。
