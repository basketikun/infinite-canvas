## 说明

- 推荐使用 CLI 本地版：作品、渠道凭据保存在启动时选定的目录，外部 Agent 通过 MCP 操作画布。
- 纯 Web 版为静态站点：作品与 API Key 保存在当前浏览器，由浏览器直接请求模型服务，不支持外部 Agent 连接。
- 两种模式都不提供云同步，跨设备可自行配置 WebDAV 同步插件。
