# 画布节点操作手册

画布底部可以创建文本、图片、视频、音频和组。前四种节点在自己的生成面板里接收结果。组用来整理节点，也可以连接到生成节点提供参考。

## 文本节点

文本节点用于保存提示词、草稿、说明文案和 AI 生成的文字结果。它既可以作为独立文本内容，也可以作为其他节点的生成参考。

### 编辑文本内容

- 双击文本节点内容区域，直接编辑节点里的文字。
- 选中文本节点后，点击顶部工具栏的“编辑文字”，进入文字编辑状态。
- 顶部工具栏的“缩小”和“放大”用于调整文本节点字号。

### 用下方对话框生成或修改文本

- 选中文本节点后，点击顶部工具栏的“编辑”，打开节点下方对话框。
- 文本节点下方对话框只用于生成或改写文本，不承担生图功能。
- 当文本节点为空时，输入框用于填写想生成的文本内容；点击发送后，结果会回填到当前文本节点。
- 当文本节点已有内容时，输入框用于填写想把本段文本修改成什么；点击发送后，改写结果会替换当前节点的文字。要保留原稿，可以先复制节点。
- 输入内容可以手写，也可以从提示词库选择。
- 输入框支持 `@` 引用已连接的图片、文本、视频、音频资源；`@` 引用图片时会在输入框内直接显示真实缩略图，发送时按当前连接自动编号交给模型。
- 对话框里的模型下拉来自全局配置里已拉取的模型列表；选择结果只作用于当前节点，不会修改其它节点或全局默认模型。
- 如果下拉中没有模型，需要先打开配置弹窗拉取模型列表，并设置默认生图模型和默认文本模型。

### 用文本节点生成图片

- 先在文本节点中准备好要用于生图的文本内容。
- 点击文本节点顶部工具栏的“生图”按钮。
- 会在右侧创建一个图片节点，并把文本连到它作为参考。
- 在图片节点下方选择模型、分辨率、宽高比和数量，点击「生成」。结果显示在该图片节点。

### 用图片节点继续生成图片

- 选中空图片节点后点击“生成”，会直接在当前节点里生成结果。
- 当数量为 `1` 时，生成结果会直接回填到当前图片节点。
- 当数量大于 `1` 时，可以在同一个图片节点内展开批次，查看和选择主图。
- 如果图片节点本身已经有内容，则会沿用已有图片作为参考图，再生成新的图片批次。
- 每个生成出来的图片节点都会在自身 `metadata` 下记录提示词、生成类型、模型、尺寸、质量、数量和参考图引用，方便后续重试。
- 如果重试时参考图已经丢失或无法恢复，系统会直接提示，避免误发空的图生图请求。

### 视频节点

- 工具栏可以新建视频节点，也可以拖入或上传本地视频文件。
- 视频节点使用原生播放器展示内容，可在节点内直接播放、暂停和拖动进度。
- 在视频节点下方输入提示词并点击「生成」，新视频会回填到当前节点。
- 视频节点会读取上游文本作为 prompt，读取上游图片作为参考图，读取上游视频作为参考视频，读取上游音频作为参考音频，并在输入预览里显示这些参考。未配置调用脚本时，OpenAI 和 Gemini 内置请求与插入模板使用相同字段；自定义视频调用脚本可通过 `videos`、`audios` 变量读取这些参考文件。
- 视频设置使用 `480p` / `720p` / `1080p` 与 `1:1`、`3:4`、`4:3`、`16:9`、`9:16`、`21:9` 或自动计算宽高，时长为 4–30 秒滑杆。也支持「首尾帧」和「全能参考」两种模式。首尾帧模式下 1 张图作为首帧、2 张图作为首尾帧发送专门字段；超过 2 张图时即使选了首尾帧也会按全能参考发送。内置请求和调用脚本都会使用解析后的 `frames` 或 `reference`。
- OpenAI 风格接口使用 `POST /v1/videos`、`GET /v1/videos/{id}` 和 `GET /v1/videos/{id}/content`，按模式发送 `first_frame` / `last_frame` 或 `image[]`，并可附带 `video[]` / `audio[]`。采用 Gemini 协议的模型通过 `models/{model}:predictLongRunning` 并轮询 operation，按模式发送 `image` / `lastFrame` 或 `referenceImages`。
- 创建远端任务后会把任务 ID 写入视频节点；刷新页面后会自动继续查询任务状态，也可点击「获取任务状态」手动拉取，直到生成成功、任务失败或查询请求报错。

### 音频节点

在音频节点下方输入文字或连接文本参考，选择音频模型和声音后点击「生成」。再次生成会在同一节点更新音频。

## 组节点

组节点用来把多个节点收成一块，方便一起移动，也可以作为生成输入一次性引用组内资源。

- 框选或按住 `Shift / Ctrl / Cmd` 点选多个节点后，会显示包住全部选中节点的圆角虚线框，框上方出现「打组」。
- 点击「打组」或按 `Ctrl / Cmd` + `G`，会新建一个组节点包住这些内容，节点保持原位置。
- 选中组后，可用顶部工具条的「解散组」、右键菜单，或 `Ctrl / Cmd` + `Shift` + `G` 取消分组。
- 也可以先在工具栏新建空组，再把节点拖进去；拖出组外会自动取消归属。
- 把组连到生成节点后，组内有内容的图片、视频、音频、文本和可引用扩展节点都会作为输入。

## 推荐流程

1. 新建文本节点，写入图片创作想法。
2. 打开文本节点下方对话框，让 AI 优化或扩写这段提示词。
3. 改写结果回填到当前文本节点。
4. 确认文本节点内容后，点击顶部工具栏“生图”。
5. 在自动创建的图片节点中调整参数，点击「生成」。
