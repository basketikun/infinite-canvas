# Codex App 插件

Infinite Canvas 提供了一个 Codex App 插件，用来把 Codex 和本地版画布连接起来。安装后，你可以直接在 Codex 中说“打开 Infinite Canvas”，让 Codex 打开画布、读取节点、创建节点并触发生成流程。

插件源码位于仓库的 `agent-plugins/infinite-canvas/` 目录。

## 安装方式

在终端运行：

```bash
codex plugin marketplace add basketikun/infinite-canvas --sparse .agents/plugins --sparse agent-plugins/infinite-canvas
codex plugin add infinite-canvas@infinite-canvas-local
```

不需要手动 clone 仓库，Codex 只拉取插件需要的目录。安装完成后，建议新建一个 Codex 对话，让新的 skill 和 MCP 工具完整加载。

### 本仓库开发调试安装

如果你正在 Infinite Canvas 仓库中开发插件，可以直接使用仓库自带的 marketplace：

```bash
cd /path/to/infinite-canvas
codex plugin marketplace add "$(pwd)"
codex plugin add infinite-canvas@infinite-canvas-local
```

仓库内的 `.agents/plugins/marketplace.json` 已经指向 `./agent-plugins/infinite-canvas`，适合开发者本地调试。

## 使用插件

新建 Codex 对话后，可以直接说：

```text
打开 Infinite Canvas 新建画布 并连接好Codex
```

插件会启动本地服务，然后在右侧打开服务提供的画布页面并自动新建画布，MCP 工具直接操作这个页面。只有明确要求使用本地项目时，插件才会在仓库中运行 `pnpm dev`。

画布打开后可以继续让 Codex 操作画布：

```text
读取当前画布并总结节点结构
根据选中节点创建一组生图提示词
把这些节点整理成一个生成流程
```

## 更新插件

普通业务代码变更通常不需要更新插件。只有改了下面这些内容时，才建议重新安装或刷新插件：

- `agent-plugins/infinite-canvas/.codex-plugin/plugin.json`
- `agent-plugins/infinite-canvas/.mcp.json`
- `agent-plugins/infinite-canvas/skills/` 下的技能说明
- 插件暴露的 MCP、app 或入口脚本

运行 `codex plugin marketplace upgrade infinite-canvas-local` 拉取最新插件，更新后建议开启新对话，避免旧对话继续使用缓存中的技能和 MCP 工具。

## 手动排查

插件默认通过下面的 MCP 命令连接本地服务：

```bash
npx -y @basketikun/infinite-canvas@latest mcp
```

如果需要手动排查，先启动本地服务：

```bash
npx -y @basketikun/infinite-canvas@latest serve
```

从启动输出的「打开地址」取得服务地址后，打开：

```text
<打开地址>/canvas?mode=new
```

`mode=new` 会让网页自动创建具体画布，不需要手动点击“新建画布”。
