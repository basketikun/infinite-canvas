# 功能介绍

本文档记录 1.0 已经实现的主要功能。CLI 本地版、桌面版与纯 Web 版共用同一套工作台，差异见文末「运行模式差异」。

## 首页

- 默认打开首页，标题下方提供「创作 / 画布」切换：创作显示与创作页一致的输入框，画布显示最近画布和新建入口。
- 侧栏「创作」进入独立创作页，只显示标题和输入框，不展示素材，也不会自动打开最近对话。
- 首页下方展示提示词库素材，桌面端一行四个，不提供搜索和分类；点击可查看详情、复制或加入我的资产。
- 桌面端使用可展开/收起的左侧竖栏导航，收起后点击 logo 或底部按钮展开；导航包含画布、创作、资产、素材、最近创作对话和画布历史；创作对话可通过「...」重命名或删除；两个分组右侧的 + 分别进入创作页和新建画布。顶部横栏左侧完整预留公告信息位置，窄屏使用顶部导航。

## 画布项目

- 支持创建多个画布项目，支持重命名、删除、批量选择和批量删除。
- 支持导出与导入画布。
- 画布未保存时可以重试、将当前内容另存为新画布，或重新加载上次保存的内容；删除未完成时可以重试删除。
- 窄屏时可从顶部打开导航，选择页面、点击遮罩或按 Escape 均可关闭；短屏上可滚动导航列表。

## 无限画布

- 支持拖动画布、滚轮缩放、缩放滑杆和重置视图。
- 支持小地图定位，可开关小地图。
- 支持点阵、网格线、空白三种背景。
- 支持浅色和深色主题。
- 支持框选、多选、全选、取消选择、删除选中。
- 支持复制粘贴节点和节点之间的连线。
- 支持撤销和重做节点、连线、视口、背景和助手会话变化。
- 支持节点连线，并高亮当前节点相关的上下游节点和连线。
- 支持快捷键帮助，覆盖缩放、框选、全选、复制粘贴、撤销重做、删除、退出选择和拖入图片。

## 节点

内置节点：

- 文本节点：保存提示词、说明文案，也可直接生成文本。
- 图片节点：展示上传、生成或来自资产的图片，可直接生成图片。
- 视频节点：上传或生成视频，使用原生播放器预览。
- 音频节点：上传或生成音频。
- 组：把多个节点归为一组，可整体移动，也可作为生成参考。

插件可以注册更多节点类型，见「插件」。

节点支持：

- 拖拽移动。
- 四角缩放。
- 图片节点等比缩放或自由比例切换。
- 查看节点基础信息和 JSON。
- 删除、复制、粘贴。
- 通过左右连接点建立上下游关系。

## 图片工作流

- 支持上传图片到新节点。
- 支持拖拽图片文件到画布。
- 支持替换已有图片节点内容。
- 支持下载图片节点。
- 支持把图片节点保存到「资产」。
- 支持图片裁剪，并把裁剪结果生成为新的图片节点。
- 支持本地多角度变换，并把结果生成为新的图片节点。
- 支持生成失败后重试。
- 批量生成多张图片时会先展示为图片组节点，支持叠卡预览、展开查看全部结果并设置主图。

## AI 生成

纯 Web 由浏览器使用已配置的渠道和模型发起请求，也可在设置中启用本机代理；CLI 和桌面版通过自身的本地服务调用模型。

- 支持文本、图片、视频和音频生成，模型按用途配置。
- 每个模型选择一种调用方式：内置调用方式覆盖 OpenAI 兼容等常见协议，也可编写、导入、导出自定义调用脚本，或使用插件提供的调用方式。详见[调用脚本开发](/docs/development/call-scripts)。
- 可配置默认模型，以及图片质量、比例、数量和视频比例、清晰度、时长、声音、水印等生成偏好。图片与视频尺寸分别保存。
- 生成失败时尽可能显示模型服务返回的原始报错。

节点下方的输入框支持 `@` 引用已连接的图片、文本、视频、音频资源；引用图片时直接显示缩略图，发送时按当前连接自动编号交给模型。

视频生成可从文本节点读取 prompt，从图片节点读取参考图。生成成功后会把视频插入画布为视频节点并使用原生播放器预览。

「创作」页把图片和视频生成合并在同一个对话里，底部输入框可切换图片创作或视频创作。生成结果按对话保留，左侧可以新建、切换和删除创作记录；每条结果支持预览、加入素材库、下载，图片还可以直接加入参考图。

## 画布助手与外部 Agent

画布右侧助手使用渠道中的文本模型，直接调用画布工具读写当前画布，纯 Web 与本地版都可使用。

CLI 本地版和桌面版还可在「设置 → Agent配置」中复制 MCP 配置，让 Codex、Claude Code 等外部 Agent 操作当前画布；纯 Web 版不支持外部 Agent 连接。原理见 [MCP 连接与画布聊天](/docs/development/canvas-mcp)。

画布右侧助手面板支持：

- 文本问答。
- 生图。
- 读取当前选中节点作为引用。
- 自动把选中节点的上游节点也纳入引用。
- 粘贴图片到助手输入框并插入画布。
- 查看消息或草稿中的多张图片时，可以逐张切换和缩放，关闭后回到原来的聊天位置。
- 历史会话。
- 删除单条或多条会话。单条删除失败时可在原会话重试，其他会话仍能继续聊天。
- 重试回答。
- 把助手生成的文本插入画布。
- 把助手生成的图片插入画布。
- 收起助手面板后，当前回复继续。重新展开可回到最新消息，或停止当前会话的这次回复。
- 输入框随内容增高，按 Shift+Enter 换行、Enter 发送。确认中文输入法中的候选文字时不会发送消息。

## 插件

插件可以扩展页面、导航、设置、布局、主题、画布节点、调用方式和同步方式：

- 「设置 → 插件」内置插件市场，可一键安装、更新、启用、停用和卸载，也支持上传插件包。CLI 还可用 `infinite-canvas plugin` 命令管理。
- 官方插件：主题、调用统计、WebDAV 同步、多格式渲染器（HTML、Markdown、SVG）、3D 全景节点和 3D 导演台。
- 提供 TypeScript 插件 SDK、[插件开发文档](/docs/development/plugin-development)和[最小插件模板](https://github.com/basketikun/infinite-canvas/tree/main/plugins/template)；CLI 本地版还支持直接放在工作区 `plugins/` 下的单文件插件。
- 插件面板显示插件版本，并对可升级的插件给出提醒。
- 画布插件菜单操作失败时，顶部显示简短的中文提示。可以重新打开菜单继续操作；切换画布或停用插件后不再显示旧操作的错误。
- 插件管理操作完成后在顶部显示成功提示，配色跟随工作台主题，约 3 秒后自动消失。
- 画布插件侧栏跟随工作台主题，支持窄屏与导演台全屏布局；下拉菜单可用方向键选择，Escape 逐层关闭，关闭侧栏后焦点回到打开入口。
- 悬停在画布底部或节点工具栏按钮上，可以查看操作提示。禁用按钮也支持悬停和键盘焦点提示，插件提供的工具栏内容可使用同一套提示。

Codex App 插件的安装与使用见 [Codex App 插件](/docs/overview/codex-app-plugin)。

## 素材（提示词库）

- Web 首页可打开示例图片并在组内切换，支持旋转、翻转、拖动、滚轮与双指缩放。

前台提示词库支持：

- 按标题或正文搜索。
- 按分类筛选；同时选中多个标签时可查看匹配其中任一标签的提示词。
- 按来源筛选。
- 查看提示词详情。
- 查看封面和结果图。
- 复制提示词。
- 把提示词加入「资产」。

提示词管理支持：

- 7 个内置来源可独立启用、查看和拉取，也可按设定周期批量更新。
- 可添加、编辑和删除自定义标准 JSON 来源。保存失败时可保留输入并在原处重试，取消编辑会保留原来的来源配置。
- 查看单个来源时每页显示 10 条，可展开详情、复制提示词或加入我的资产；加入成功后可从资产页继续编辑。
- 刷新失败时保留该来源上一次成功的缓存，列表显示各自的状态和成功时间。编辑来源地址后会使用新地址重新拉取。
- 跨已启用来源搜索提示词，按标签筛选，查看详情、复制提示词或插入画布。

7 个内置来源为 Banana Prompt Quicker、DavidWu GPT Image 2、Freestylefly GPT Image 2、Awesome GPT Image、Awesome GPT-4o、YouMind GPT Image 2 和 YouMind Nano Banana Pro。应用从 [Image Prompts](https://github.com/yukkcat/image-prompts) 统一仓库读取标准 JSON，由浏览器前端直连并缓存到 IndexedDB。完整来源见[第三方提示词来源](/docs/overview/third-party-prompt-repositories)。

## 资产

「资产」页保存你自己的文本、图片、视频等素材，支持文件夹整理，以及：

- 新增文本素材和图片素材。
- 编辑素材标题和文本内容。
- 删除素材。
- 按关键词搜索。
- 按类型筛选。
- 分页浏览。
- 复制文本素材。
- 下载图片素材。
- 从提示词库和画布节点加入素材。
- 在画布中插入素材。

## 配置和同步

- 设置中的本地存储概览可查看分类占用。Web 显示浏览器提供的站点空间信息，本地工作区另列所在磁盘的容量。可打开支持浏览的分类查看内容，私有配置只显示汇总。
- 存储明细可按类别搜索、翻页，查看文件使用位置。浏览列表使用已有预览，可按需播放或下载原文件。
- 点击顶部版本号可查看版本说明和检查更新。手动检查会给出完成或失败提示；获取失败时仍可阅读随应用提供的说明。

- 复制配置说明或连接 JSON 后，工作台顶部会显示所复制的内容类型，较长的提示会在窄屏上换行。

- 不需要账号登录。
- 设置支持多个模型渠道、默认模型和生成偏好。
- 渠道与分组在桌面可从列表切换，窄屏可从下拉框切换。用键盘删除时，确认窗口先选中「取消」，也可按 Tab 选择「确定」。
- 每个分组独立保存密钥。Web 可切换显示已保存的密钥，CLI 显示是否已设置，可输入新值替换或点击「清除密钥」。
- 渠道分组可手动添加或拉取模型、按名称筛选，并配置用途与调用脚本。搜索其他名称时保留已有选择，切换分组会清空选择。
- 纯 Web 可在「本地代理」中复制启动命令、设置地址并测试连接。开关和地址保存成功后生效，可用于模型请求、WebDAV 和远程素材。CLI 和桌面工作台自动使用自身服务。
- 需要公开链接的参考素材可上传到配置的 S3 兼容对象存储。支持两种存储桶寻址方式，已有公开链接可直接使用。保存上传配置后才会发送文件。

## 运行模式差异

| | CLI 本地版 / 桌面版 | 纯 Web 版 |
| --- | --- | --- |
| 作品与素材 | 启动时选定的本机目录 | 当前浏览器 |
| 模型密钥 | 本地服务保存，页面只显示是否已设置 | 当前浏览器，由浏览器直接请求模型服务 |
| 外部 Agent（MCP） | 支持 | 不支持 |
| 本地代理 | 不需要，自动使用自身服务 | 可选，用于模型请求、WebDAV 和远程素材 |

两种模式都不提供云同步，1.0 也不读取 0.x 版本留下的浏览器数据。画布更适合桌面端使用，移动端触控体验还未系统完善。
