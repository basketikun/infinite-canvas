# Licensing

DSH FreeCanvas uses component-level licensing rather than applying one license to every directory.

- Upstream-derived canvas code and components without a separate license remain under the root [MIT License](https://github.com/JustinQiuck/dsh-freecanvas/blob/main/LICENSE), including the original `basketikun/infinite-canvas` notice.
- `plugins/dsh-freecanvas` uses [Elastic License 2.0](https://github.com/JustinQiuck/dsh-freecanvas/blob/main/plugins/dsh-freecanvas/LICENSE) starting with plugin version `0.2.0`. Its package also contains the upstream MIT notices required by its third-party components.
- Plugin version `0.1.0` was previously made available under MIT. Later licensing does not retroactively replace rights already granted for that historical version.
- Future Pro or enterprise modules are not part of the current public bundle and may require a separate commercial agreement or EULA when released.

See the repository [LICENSING.md](https://github.com/JustinQiuck/dsh-freecanvas/blob/main/LICENSING.md) for the complete scope summary and [Project Use](/docs/business/business) for usage guidance. The applicable full license text controls each component.
