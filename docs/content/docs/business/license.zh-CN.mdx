# 许可证

DSH FreeCanvas 采用分组件授权，不再将同一个协议概括为整个仓库的唯一许可证。

## 授权范围

- 上游衍生画布代码与没有单独许可证的组件，继续使用根目录 [MIT License](https://github.com/JustinQiuck/dsh-freecanvas/blob/main/LICENSE)，并保留 `basketikun/infinite-canvas` 版权声明。
- `plugins/dsh-freecanvas` 从插件 `v0.2.0` 起使用 [Elastic License 2.0](https://github.com/JustinQiuck/dsh-freecanvas/blob/main/plugins/dsh-freecanvas/LICENSE)，发布包同时携带上游 MIT 第三方声明。
- 插件 `v0.1.0` 曾按 MIT 公开，后续版本更换协议不追溯替换该历史版本已经授予的权利。
- 未来 Pro 或企业模块不包含在当前公开 bundle 内，发布时可能需要独立商业协议或 EULA。

完整范围说明见仓库 [LICENSING.md](https://github.com/JustinQiuck/dsh-freecanvas/blob/main/LICENSING.md)。如果摘要与完整协议文本存在差异，以对应组件的完整许可证文本为准。
