# MIT 开源协议

无限画布采用 [MIT License](https://github.com/basketikun/infinite-canvas/blob/main/LICENSE)。任何个人、团队和企业都可以免费、自由地使用本项目，没有使用场景和商业用途限制。

## 项目初衷

无限画布保持开源，希望让更多人可以查看和修改代码，不被固定 API 渠道限制，接入自己的 API 与模型渠道，用画布组织提示词、参考图、素材和生成结果，搭建适合自己的 AI 创作工作流。


## 你可以做什么

- 免费使用、复制和修改代码。
- 发布原版或修改后的版本。
- 将项目用于商业产品、内部系统、私有化交付或在线服务。
- 将项目代码合并到开源或闭源软件中。
- 对项目或修改后的版本再授权或销售。

你不需要购买商业授权，也不需要公开自己的修改或业务代码。
