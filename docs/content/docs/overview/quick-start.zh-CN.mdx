# 快速开始

DSH FreeCanvas 是 DSH 的自包含画布插件。插件已经包含画布前端和本地 Agent 连接，普通用户不需要克隆仓库、启动本地端口或部署独立站点。

## 安装插件

1. 打开 DSH 插件市场。
2. 搜索并安装 **DSH FreeCanvas**。
3. 从 DSH 侧边栏打开 FreeCanvas。

画布支持会话、分屏和全画布布局。DSH 会保存上次使用的布局。

## 首次使用

1. 打开画布右上角设置。
2. 填写自己的 `Base URL`、`API Key` 和模型。
3. 新建画布，添加节点并开始生成。

画布、我的素材、生成记录和 API Key 默认保存在浏览器本地。AI 请求由浏览器直接发送到用户配置的 OpenAI 兼容接口。

## 源码开发

普通用户无需执行源码开发步骤。调试插件或参与开发时，请阅读[插件源码说明](https://github.com/JustinQiuck/dsh-freecanvas/tree/main/plugins/dsh-freecanvas)和[本地开发文档](/zh-CN/docs/development/local-development)。
