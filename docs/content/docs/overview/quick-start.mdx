# Quick Start

DSH FreeCanvas is a self-contained DSH canvas plugin. It includes the canvas frontend and local Agent connection. Users do not need to clone the repository, open a local port, or deploy a separate site.

## Install the plugin

1. Open the DSH plugin marketplace.
2. Search for and install **DSH FreeCanvas**.
3. Open FreeCanvas from the DSH sidebar.

The canvas supports conversation, split, and full-canvas layouts. DSH remembers the last selected layout.

## First use

1. Open Settings in the canvas.
2. Enter your `Base URL`, `API Key`, and models.
3. Create a canvas, add nodes, and start generating.

Canvases, My Assets, generation history, and API keys are stored in the browser by default. The browser sends AI requests directly to the configured OpenAI-compatible endpoint.

## Source development

Users do not need the source development steps. To debug or contribute to the plugin, read the [plugin source guide](https://github.com/JustinQiuck/dsh-freecanvas/tree/main/plugins/dsh-freecanvas) and [local development guide](/docs/development/local-development).
