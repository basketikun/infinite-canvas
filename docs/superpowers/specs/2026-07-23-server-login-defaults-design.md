# 服务端登录入口与默认偏好设计

## 目标

新版画布在右上角提供服务端登录与模式切换入口，恢复 v0.3 的可发现性。用户有有效服务端会话时，首次使用默认服务端模式；未登录时默认本地直连。用户一旦手动选择模式，后续刷新必须保持该选择。新用户默认使用浅色主题。

## 状态与优先级

在持久化的 AI 配置中新增 `channelModePreferenceSet` 布尔值，默认 `false`。它只表示模式是否由用户明确选择，不保存额外的模式值；实际模式仍使用既有 `config.channelMode`。

启动流程在用户会话水合完成后执行：

1. 若 `channelModePreferenceSet` 为 `true`，不修改 `channelMode`。
2. 否则，若存在有效登录令牌且运行时配置了控制平面 URL，切换为 `remote`；其余情况切换为 `local`。
3. 登录成功后切换为 `remote`，但不将它视为手动模式选择；用户之后仍可在任一入口明确选择本地或服务端。
4. 用户在顶栏或配置窗口切换模式时，同时更新 `channelMode` 并设置 `channelModePreferenceSet` 为 `true`。
5. 退出登录时切换为 `local` 并保留手动偏好标记。这样旧令牌失效或主动退出后不会保留一个无法调用的服务端模式。

老版本已保存的配置没有该标记，按未手动选择处理，使其可由会话状态获得合理默认值。没有控制平面 URL 时，服务端选项保持禁用。

## 顶栏交互

`UserStatusActions` 是普通页面和画布页面共用的右上角操作区。它新增服务端账户入口：

- 未登录时显示“登录服务端”，点击打开紧凑的登录弹窗。
- 已登录时显示用户名；下拉菜单展示当前模式、可切换“服务端模式”与“本地直连”，并提供退出登录。
- 登录失败直接在弹窗中提示错误；登录成功关闭弹窗并切换服务端模式。

配置窗口中的原服务端登录表单仍可使用，但改为调用同一套模式选择动作，保证两个入口的持久化语义一致。

## 主题

主题 store 的初始值由 `dark` 改为 `light`。Zustand 持久化会继续恢复已保存的主题，因此仅没有历史主题值的用户看到浅色默认，不覆盖已有用户的选择。

## 非目标

- 不改变控制平面的认证 API、模型 API 或供应商密钥存储方式。
- 不移除本地直连配置与渠道编辑能力。
- 不修改 Cloudflare Tunnel、Nginx 或 Docker 发布结构。

## 验收

- 无历史模式偏好时，登录会话存在则选择 `remote`，否则选择 `local`。
- 手动选择本地后，即使保持登录并刷新，仍为 `local`。
- 右上角可完成登录、模式切换与退出登录；普通页面和画布页面都可用。
- 无主题持久化数据时默认浅色；已有主题持久化数据仍被恢复。
- 前端类型检查、单元测试与生产构建通过。
