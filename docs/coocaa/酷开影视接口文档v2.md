## POST请求格式

接口定义的POST请求数据格式为，JSON格式的字符串，将body 数据按以下结构组装

```JSON
{
    "data":{"page":1,"size":2}, 
    "devInfo":{"source":"tencent"},
}
```

1. 接口文档中定义的参数，放入上面结构的data 参数中

2. 将设备信息放入上面结构的 devInfo 参数中

{
